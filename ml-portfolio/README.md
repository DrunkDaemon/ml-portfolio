# ML Portfolio
Three machine learning projects in Python.

| Project | What it shows |
|---|---|
| [1-house-price-predictor](1-house-price-predictor) | End-to-end ML: feature engineering, model comparison, tuning, explainability, Streamlit app |
| [2-digit-recognizer](2-digit-recognizer) | Classification, cross-validation, GridSearch, error analysis |
| [3-news-topic-classifier](3-news-topic-classifier) | NLP with TF-IDF, model comparison, interpretability |

## Setup
    pip install -r requirements.txt
Then follow the README inside each project folder.
